# Submission checklist

- [ ] Public repository is reachable and the final source commit is recorded.
- [ ] README quickstart was tested from the repository environment.
- [ ] Exact heading `## Qodo Code Review Evidence` is present.
- [ ] Public merged PR links are included.
- [ ] AI-assisted development disclosure is present and truthful.
- [ ] No secrets, private paths, private Drive IDs, private data, or credentials are included.
- [ ] TrueForge is visible in the primary demo.
- [ ] A real typed EdgeOpt MCP invocation is visible.
- [ ] A real Daytona sandbox execution is visible.
- [ ] A genuine human approval occurs before the final package.
- [ ] Video is approximately three minutes and shows the result clearly.
- [ ] Submission text and public links are prepared.
- [ ] Final repository commit/tag/backup is recorded after human review.
- [ ] Temporary Daytona Full Access key is deleted or rotated after submission, not before the final demo.
- [ ] No unsupported Jetson, TensorRT, Model Optimizer, GPU, memory, or latency claims are made.
